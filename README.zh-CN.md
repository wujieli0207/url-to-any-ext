## 使用方法

### 1. 从 Chrome 应用商店安装

1. 访问 Chrome 应用商店
2. 搜索 "URL to Any"
3. 点击 "添加至 Chrome" 安装扩展程序

### 2. 一键转换网页

1. 访问您想要转换的网页
2. 点击浏览器工具栏中的 URL to Any 扩展图标
3. 选择您需要的格式（Markdown、PDF、HTML 等）
